## ✨ Features

- ⚡ **Ultra Fast Performance:** Built with Vite and React 19 for blazing-fast render times.
- 🎨 **Fluid Animations:** Powered by GSAP (GreenSock) for high-performance UI transitions and scroll effects.
- 🌊 **Smooth Scrolling:** Integrated with Lenis for an effortless reading experience.
- 📱 **Fully Responsive:** Optimized across desktop, tablet, and mobile displays.
- 🚀 **Continuous Deployment:** Seamless CI/CD deployment via Vercel.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### 1. Clone the repository
```bash
git clone https://github.com/rohitpal00015-prog/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for production
```bash
npm run build
```
